## 已执行

- 正式应用目标编译、链接成功，保留并执行 Windows EXE 完整性标签规范化步骤；由同套件 `windeployqt` 部署 Qml、Network 与 TLS 后端。

- 验收进程的 PATH 仅包含部署目录和 Windows 系统目录，Qt 插件路径指向部署目录；通过部署的 Schannel 后端成功完成 HTTPS 请求。这属于本机部署检查，不能替代无开发环境机器验证。

### ElaPivot 页签调整

多页设置导航由下拉框改为 ElaPivot 后，另外执行了 34 项定向断言，浅色 150% 和深色 200% 两次均为零失败，并重新通过正式 Release 构建。覆盖初始选中页、鼠标和键盘切页、跨页草稿保留、校验失败定位、保存全部页面、保存时禁用页签、单页隐藏导航、八页横向滚动、长标题宽度及完整提示，以及最小尺寸下底部按钮可见。原生截图检查了两种主题下的页签和表单；Windows 原生边框下请求 520×360 后实测宽度为 525/529 个逻辑像素。该轮临时验收入口、数据和截图同样在交付前清理。

## 尚未执行

- 无 Qt、无开发工具的全新 Windows 机器或虚拟机部署。
- 管理员授权、真实 UIAccess 提权和降权交接、操作系统取消授权后的完整重启流程。
- 实际拔插显示器、跨显示器 DPI 动态切换、屏幕可用区域小于最小弹窗的场景。
- 系统文字单独放大、完整键盘与辅助功能验收、真实休眠恢复和跨午夜长时间运行。
- 所有配额的压力测试、代理与复杂 TLS 证书链、全面异常输入测试。

Qt 6.9.3 实测支持 Promise，但不支持 `async function` 语法；API 使用 callback。插件与宿主处于同一进程，工作线程和入口路径检查不构成安全沙箱。发布前仍需完成上述环境相关检查。
